# Pahadi Club — VIT Bhopal

A responsive cultural club website for **Pahadi Club, VIT Bhopal**, created to showcase the club's identity, events, team, and community activities.

## About the Club

Pahadi Club is a student community at VIT Bhopal celebrating the culture, traditions, music, food, clothing, and festivals of the mountain regions.

The website currently highlights cultural connections with:

- Himachal Pradesh
- Uttarakhand
- Jammu

## Website

The website is built as a responsive single-page website with smooth navigation between:

- Home
- About
- Events
- Team
- Join Us

## Features

- Responsive design for desktop and mobile
- Pahadi-inspired visual theme
- Animated mountain landscape hero section
- Falling snow animation
- Animated navigation bar
- Smooth scrolling
- Responsive mobile navigation
- About section covering the club's cultural focus
- Events showcase
- Team/member section with team-wise tabs
- Faculty coordinator section
- Join Us section
- Instagram and email links
- Responsive event cards
- Image placeholders/fallbacks for team members

## Events

The current website showcases:

### Kauthik 1.0

A Pine & Peak Carnival featuring activities such as:

- Open DJ
- Souvenir stalls
- Games
- Cultural activities
- Traditional photo booth
- Art & craft workshops

### Kauthik 2.0

The second edition of the club's carnival featuring colourful decoration, music, and campus activities.

### Uttarayani Mela

A cultural celebration featuring traditional dress, folk music, and food.
